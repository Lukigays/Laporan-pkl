Panduan Web2APK

Langkah-langkah mengubah website Laporan PKL ini menjadi aplikasi Android (APK):

  1. Pastikan aplikasi web ini sudah di-deploy/online (misal lewat Vercel, Netlify, atau GitHub Pages).
  2. Klik tombol "Buat APK via PWABuilder" di menu pengaturan.
  3. Masukkan tautan (URL) website laporan PKL Anda ke kolom yang tersedia di situs PWABuilder, lalu klik Start.
  4. Setelah analisis selesai, klik tombol Generate pada bagian opsi Android/APK.
  5. Unduh file APK yang dihasilkan dan instal langsung di perangkat Android Anda!
